Cadastro de Documentos Document Registration

Formulário detalhado com classes, subclasses e geração automática de código único (NBR 6023). Detailed form with classes, subclasses, and automatic unique ID generation (NBR 6023).

🤖

Transcrição com IA AI Transcription

Transcrição automática de fac-símiles via Claude, GPT-4o, AWS Bedrock, Ollama, LM Studio ou Tesseract OCR local. Automatic facsimile transcription via Claude, GPT-4o, AWS Bedrock, Ollama, LM Studio, or local Tesseract OCR.

📄

Exportação DOCX DOCX Export

Gera Inventário completo e Fichas-Catálogo em formato Word (.docx) prontas para publicação. Generates full Inventory and Catalog Cards in Word format (.docx) ready for publication.

🔍

Comparação de Transcrições Transcription Comparison

Visualização lado a lado com destaque visual: amarelo = texto diferente; vermelho = bloco ausente. Side-by-side view with visual highlights: yellow = different text; red = missing/extra block.

🗂️

Multi-testemunhal Multi-testimonial

Suporte a documentos mono e poli-testemunhais, com indexação de pessoas e instituições citadas. Support for single and multi-testimonial documents, with indexing of cited persons and institutions.

Armazenamento Local JSON Local JSON Storage

Dados salvos localmente em JSON. Sem nuvem obrigatória, sem conta, sem assinatura. Data saved locally in JSON. No mandatory cloud, no account, no subscription.

Sobre o Projeto About the Project

O GAMA foi desenvolvido para o projeto "Acervo Alcina Dantas (AAD): interação entre filologia, arquivística e TICs" de Pollianna dos Santos Ferreira Silva e Rosa Borges. Concebido a partir de uma perspectiva dialógica entre a Filologia e as TICs. GAMA was developed for the project "Alcina Dantas Collection (AAD): interaction between philology, archival science, and ICTs" by Pollianna dos Santos Ferreira Silva and Rosa Borges. Conceived from a dialogical perspective between Philology and ICTs.
